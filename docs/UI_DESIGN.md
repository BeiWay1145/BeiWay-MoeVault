# BeiWay-MoeVault — UI 设计文档（v0.1）

> 配套规划文档：`docs/PLAN.md`。本文档细化前端（Vue 3 + Element Plus）的布局、页面、组件与交互。
> 线框为 ASCII 示意，最终以实现为准。

---

## 1. 设计原则

1. **浏览优先**：图库的本质是"快速看到、快速筛选"，图片墙是核心，一切操作不打断浏览流。
2. **操作可逆**：删除永远先进回收站；批量操作前有确认弹窗；破坏性操作（永久删除、移动进库）二次确认。
3. **任务可见**：所有后台流水线（导入/查重/打标/评分）在界面有进度与失败入口，不黑盒。
4. **组合筛选一致**：筛选器在"图库"与"搜索"页共享同一套状态模型，可随时保存为智能视图。
5. **性能体感**：虚拟滚动 + 缩略图懒加载 + 骨架屏，万级列表滚动不掉帧。

| 路由 | 页面 | 说明 |

| `/` | 总览 Dashboard | 统计 + 快捷入口 + 进行中任务 |

## 4. 页面详细设计

### 4.1 总览 `/`

```
┌─ 统计卡片区（4~6 张）──────────────────────────────────────┐
│ [🖼 总数 128,432] [📅 本月导入 1,204] [👯 冗余候选 3,287]     │
│ [🏷 待打标 0]      [⭐ 待评分 0]     [平均美学分 3.8]          │
├─ 进行中任务 ──────────────────────────────────────────────┤
│ [导入批次 #12 ████████░░ 78%  128/164  速率 8/s  剩余 ~4s]  │
│ [SauceNAO 溯源 ███░░░░░░░ 31%  队列 2,140 预计 17h]        │
├─ 最近导入 ────────────────────────────────────────────────┤
│ [img][img][img][img][img][img][img][img]  → 查看全部        │
├─ 快捷筛选 ────────────────────────────────────────────────┤
│ [本月新图] [高分佳作(≥4.5)] [低清晰度] [danbooru 来源] [收藏] │
└───────────────────────────────────────────────────────────┘
```

- 统计卡片：点击跳转对应筛选视图（如"冗余候选"→ 查重页）。
- 进行中任务：实时进度（WS 推送），可暂停/跳转到任务中心。
- 快捷筛选：预置筛选表达式，点击直达图库页并应用。

### 4.2 图库 `/library`

```
┌─ 工具栏 ──────────────────────────────────────────────────┐
│ [☷ 网格|☰ 列表|≣ 瀑布流] [排序▾] [筛选状态: 3 个条件 ✕]  [批量操作▾] │
├─ 筛选 chips（来自导航/搜索页带入）──────────────────────────┤
│ [日期: 2024-06 ✕] [标签: 1girl ✕] [美学≥4.0 ✕] [+ 更多]     │
├─ 图片墙（虚拟滚动）───────────────────────────────────────┤
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                              │
│  │img │ │img │ │img │ │img │  悬停: 快捷预览/加标签/入回收站   │
│  └────┘ └────┘ └────┘ └────┘                              │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐  选中: 蓝色边框 + 角标         │
│  │img │ │img │ │img │ │img │                              │
│  └────┘ └────┘ └────┘ └────┘                              │
├─ 底部 ────────────────────────────────────────────────────┤
│ [已加载 1,024 / 12,430]  滚动无限加载                        │
└───────────────────────────────────────────────────────────┘
```

- **三种视图**：
  - 网格：固定卡片宽（默认 200px），`object-fit: cover`，密度高。
  - 瀑布流：列数自适应（按容器宽），`object-fit: contain` 按原比例，适合插画。
  - 列表：一行一条（缩略图 + 文件名 + 尺寸 + 日期 + 美学分 + 标签预览），适合管理。
- **图片卡片**：缩略图（WebP 512px）+ 选中态 + 冗余候选角标（⚠ 模糊）+ 黑名单遮罩（模糊化，点击提示）。
- **批量操作**（选中后出现操作栏）：加标签、入回收站、导出、sidecar 导出、重算评分。
- 键盘：`←/→` 翻页、`Ctrl+A` 全选当前屏、`Delete` 入回收站、`Enter` 打开详情。
- 空状态：引导"导入图片"。

### 4.3 单图详情 `/library/:id`

```
┌────────────────────────────┬───────────────────────────────┐
│  ImageViewer                │  MetaPanel                     │
│  ┌──────────────────────┐   │  ┌─ 基本信息 ────────────────┐ │
│  │                      │   │  │ 尺寸 1920×1080 · PNG 2.1MB │ │
│  │       大图            │   │  │ 日期 2024-06-12 (EXIF)    │ │
│  │   （缩放/旋转/翻页）    │   │  │ 清晰度 8.2  ⭐美学 4.6/5  │ │
│  │                      │   │  │ 来源 danbooru  [跳转🔗]    │ │
│  └──────────────────────┘   │  ├─ 标签 ────────────────────┤ │
│  [◀ 上一张] [▶ 下一张]        │  │  [1girl][long hair][smile]│ │
│                              │  │  [original]  (danbooru)  │ │
│  ┌─ 相似图片 ──────────────┐  │  [landscape][sky] (本地)    │ │
│  │ [img][img][img][img]  → │  │  [我的收藏][壁纸] (手动)     │ │
│  └─────────────────────────┘  │  [＋ 添加标签] [中/EN 切换]   │ │
│                              │  ├─ 操作 ────────────────────┤ │
│                              │  │ [入回收站] [导出] [sidecar] │ │
│                              │  └───────────────────────────┘ │
└────────────────────────────┴───────────────────────────────┘
```

- **ImageViewer**：缩放（滚轮/按钮，1%–400%）、旋转、上一张/下一张（不退出详情，预加载相邻原图）、全屏。
- **MetaPanel**：
  - 基本信息：尺寸/格式/大小/日期（EXIF 或文件时间，来源标记）/清晰度/美学分（星级+数值）。
  - 标签：按来源分组显示（danbooru / gelbooru / 本地 / 手动），标签点击 → 跳转搜索该标签；黑名单标签置灰。手动标签可删除。添加标签带联想（现有标签自动补全）。
  - 来源：SauceNAO 溯源相似度 + 原帖链接（外链跳转），点击"重新溯源"。
  - 操作：入回收站（确认）、导出原图、生成 sidecar .txt、复制路径。

```
┌─ 顶部搜索框 ──────────────────────────────────────────────┐
│ [🔍 输入标签/文件名关键字（FTS）..................]          │
```

- 筛选状态模型与图库页共享（`useLibraryStore`），chips 显示已激活条件，可单独移除。

- FTS 关键字支持标签名（含中文翻译字段）与文件名。

### 4.5 查重管理 `/dedup`

```
┌─ 统计条 ──────────────────────────────────────────────────┐
│ 重复组 1,024 | 涉及图片 4,311 | 冗余候选 3,287 | [全库重扫]    │
├─ 重复组列表 ──────────────────────────────────────────────┤
│ ┌─ 组 #2048 ────────────────────────────────────────────┐ │
│ │ [代表图]  共 4 张 · 冗余 3 张   [对比] [保留最优→回收站]  │ │
│ │   展开:  [img✓清晰 8.2][img⚠5.1][img⚠3.0][img⚠2.4]     │ │
│ └───────────────────────────────────────────────────────┘ │
│ ┌─ 组 #2049 ...                                            │
└───────────────────────────────────────────────────────────┘
```

- 每组默认折叠，展开显示全部成员缩略图；**最优图**（清晰度最高）带 ✓ 标记，冗余候选带 ⚠ + 清晰度分数。
- **组内对比**：选择组内任意两张 → 对比弹窗（并排显示 + 各自清晰度/美学分/尺寸），帮助用户确认删除对象。
- **批量操作**：勾选多组 → "全部保留最优，其余入回收站"（一次确认）；或逐张勾选成员精确删除。
- 冗余候选角标同步出现在图库（⚠），点击直达对应组。

### 4.6 回收站 `/trash`

```
┌─ 工具栏 ──────────────────────────────────────────────────┐
│ [🔍 搜索] [筛选: 原因▾ 时间▾]  [🗑 清空回收站(危险)]          │
├─ 列表（缩略图 + 原路径 + 原因 + 删除时间）──────────────────┤
│ [img] 组 #2048 · 冗余删除 · 2024-06-12  [恢复] [永久删除]    │
│ [img] 手动删除   · 2024-06-11  [恢复] [永久删除]             │
└───────────────────────────────────────────────────────────┘
```

- **恢复**：文件移回库目录，元数据恢复 active。
- **永久删除**：二次确认弹窗（提示不可恢复），可选"同时删除缩略图"。
- **清空**：统计数量 + 强确认（输入"清空"或点击二次确认）。
- 软删除期间图片不参与搜索/统计（可配置"包含回收站"搜索）。

- 任务卡片实时更新（WS）；进行中任务可暂停/取消/调整优先级。
- 失败列表显示错误摘要 + 展开详情；支持单个重试、全部重试、忽略。
- 断点续跑提示：任务中断后重启软件自动恢复 pending 队列。

```
┌─ 工具栏 ──────────────────────────────────────────────────┐
│ [🔍 搜索标签] [＋新建自定义标签] [导入/导出 CSV] [中文字典: ●开] │
├─ 标签表 ──────────────────────────────────────────────────┤
│ 名称(EN)     中文      分类      来源   关联图数  操作          │
│ 1girl        女孩      general  自动   12,304   [合并][重命名] │
│ original     原创      meta     自动    8,911   [合并][重命名] │
│ 我的壁纸      -        自定义   手动      128   [合并][重命名] │

```

- **重命名/合并**：弹窗选择目标标签，确认后更新所有关联（事务内完成，可预览影响数量）。
- **黑名单**：屏蔽后图库默认隐藏/模糊相关图片（可在设置切换为"直接隐藏"或"模糊提示"）。
- **中文字典**：开关即时生效（仅显示层映射，不改存储）。

### 4.9 设置 `/settings`

按分组 Tab：图库 | SauceNAO | 打标 | 查重 | 美学 | 回收站 | sidecar | 通用

| 分组 | 关键项 |
|---|---|
| 图库 | 库目录路径（含"迁移库目录"）、缩略图规格、缩略图重建、导入默认模式 |
| SauceNAO | API key（密码框+测试按钮）、API 等级（限流速率）、相似度阈值、缓存清理 |
| 打标 | cl_tagger 模型路径、置信度阈值、模型重载 |
| 查重 | pHash 汉明阈值滑杆（0–64）、清晰度算法（Laplacian/其他）、全库重扫按钮 |
| 美学 | 模型路径、归一化显示方式、全量重算按钮 |
| 回收站 | 自动清空开关 + 保留天数、当前占用统计 |
| sidecar | 默认开关、导出目录策略 |
| 通用 | 语言（中/EN）、中文字典、主题（跟随系统/浅/深）、日志级别、数据备份/恢复 |

- 所有修改即时写入 `settings` 表并热生效；危险项（迁移库目录、全量重算）红色警告 + 确认。

## 6. 关键交互流程

### 6.1 导入流程
```
点击[导入+] → 选择文件/文件夹（可多选来源）
→ 导入弹窗：显示计划（N 个文件 / 总大小 / 目标库剩余空间 / 将执行"移动进库"警告）
→ 确认 → POST /api/import → 创建 import_batch → 任务入队
→ 总览/任务中心实时进度；完成后自动跑查重→溯源→打标→评分流水线
→ 图库中出现新图（按导入时间排序可见）
```

### 6.2 查重确认流程
```
流水线完成 → 查重菜单角标"3,287"
→ 进入查重页 → 按组展开 → 组内对比确认
→ [保留最优，其余入回收站] → 确认弹窗（显示将回收 N 张，可恢复）
→ 入回收站 → 图库中 ⚠ 标记消失
```

### 6.3 删除 / 恢复流程
```
任何删除（单张/批量/查重确认）→ 文件移入 data/recycle + status=recycled
→ 回收站可 [恢复]（移回库目录）或 [永久删除]（二次确认）
→ 清空回收站 = 批量永久删除（强确认）
```

### 6.4 打标失败处理
```
任务中心失败列表 → 展开错误详情（如"溯源相似度不足"）
→ [重试]（重新溯源）/[忽略]（标记为本地打标）/[改为手动打标]
→ 单图详情可手动"重新溯源"
```

## 7. 状态管理（Pinia）

| Store | 职责 |
|---|---|
| `useLibraryStore` | 当前筛选条件、排序、视图模式、分页/游标、选中集合 |
| `useImageStore` | 单图详情、标签编辑操作、相似图 |
| `useDedupStore` | 重复组列表、展开状态、批量选择、对比对 |
| `useTaskStore` | 任务列表、实时进度（WS 事件驱动）、失败重试 |
| `useTagStore` | 标签索引、分类、黑名单、中文字典开关 |
| `useTrashStore` | 回收站列表、筛选、批量恢复/删除 |
| `useSettingsStore` | 设置项缓存与更新（乐观更新 + 后端确认） |

**WS 事件协议（草案）**：`task.progress` / `task.failed` / `library.updated` / `dedup.updated` / `stats.updated`，前端按事件刷新对应 store，避免轮询。

## 8. 视觉规范（初始）

- **主题**：Element Plus 定制，主色建议靛蓝 `#4F6BFF`（图库类工具常见）、成功/警告/危险沿用 EP 语义色；深色模式完整支持。
- **密度**：图片墙卡片默认 200px 网格 / 瀑布流列宽 240px；列表行高 72px。
- **图片呈现**：网格 `cover` 裁切；瀑布流 `contain` 保比例；详情大图 `contain` 黑色画布。
- **动效**：仅用于状态反馈（悬停、选中、进度），不做花哨动画。
- **字体**：系统字体栈 + 数字用等宽（进度/统计对齐）。
- **骨架屏**：图片加载统一骨架占位，避免布局跳动。
